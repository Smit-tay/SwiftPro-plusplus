= mode 0
= enc.ref B1655 L2673 R1664
= enc.raw B1654 L2820 R1403
~ boot quiet

# G2203: ok once every queued move has finished (Marlin_main.cpp:7642-7646). Its reply comes after the move's.
#: change Q-80
> #1 G2202 N0 V100 F1000
> #2 G2203
~ idle
< $1 ok
< $2 ok
> #3 G2203 V1
< $3 E21

# M2211 N0: the AVR's own EEPROM, read only (3.x uArmAPI.cpp:686-730): 900 = the work mode byte, 910 = the height
# offset float, 818 = the reference flag 0xBB; T2 little-endian. M2212 N0 is refused (Q-80).
#: change Q-80
> #27 M2211 N0 A900 T1
< $27 ok V0
> #28 M2211 N0 A910 T4
< $28 ok V74.5500
> #29 M2211 N0 A818 T2
<re ^\$29 ok V-?[0-9]+$
> #30 M2211 N0 A4093 T4
< $30 E21
> #31 M2212 N0 A900 T1 V1
< $31 E21

# M2211/M2212 N1: the external EEPROM (V4.10.0 uarm_protocol.c:1773-1860). Erased reads 255; T2 big-endian.
#: change Q-81 (V4.10.0 replied with whatever it read even with no chip; we reply E26)
> #32 M2211 N1 A0 T1
< $32 ok V255
> #33 M2212 N1 A10 T1 V42
~ ms 20
< $33 ok
> #34 M2211 N1 A10 T1
< $34 ok V42
> #35 M2212 N1 A20 T2 V-2
~ ms 20
< $35 ok
> #36 M2211 N1 A20 T2
< $36 ok V-2
> #37 M2211 N1 A20 T1
< $37 ok V255
> #38 M2212 N1 A30 T4 V-12.5
~ ms 20
< $38 ok
> #39 M2211 N1 A30 T4
< $39 ok V-12.5000

# A float across a page boundary (126-129): written in two parts, each waiting for the chip's write cycle (5 ms in
# the model), so the reply comes about 10 ms later.
#: change Q-81
> #40 M2212 N1 A126 T4 V3.25
~ ms 20
< $40 ok
> #41 M2211 N1 A126 T4
< $41 ok V3.2500
# 3.25 = 0x40500000, little-endian: byte 128 is 0x50.
> #42 M2211 N1 A128 T1
< $42 ok V80

# Bad fields: T3, N2, address past 65524, a byte above 255.

< $44 E21
> #45 M2211 N1 A65525 T1
